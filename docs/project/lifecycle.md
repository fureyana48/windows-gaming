# Core Gaming Lifecycle

## Phase 1 — Baseline
Identify OS, GPU, power plan, pagefile, storage, and sleep capabilities.

## Phase 2 — Cleanup
Remove temporary data, clear Windows Update download cache, and execute DISM component cleanup.

## Phase 3 — Gaming policy
Enable Game Mode and disable background Game DVR capture.

## Phase 4 — Reboot
Reboot to ensure policy persistence.

## Phase 5 — Validation
Validate actual registry, power, GPU, storage, pagefile, and free-space state.

## Phase 6 — Freeze
Once validation passes, Core Gaming v1.0 is frozen.

## Phase 7 — Workload layer
The next layer contains game installation, launchers, game-specific configuration, benchmark execution, and gameplay.
